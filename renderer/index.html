Review Pull Request
Review a PR by providing a Jira ticket (e.g. AINEX-27) or GitHub PR URL. The app will fetch PR details, changed files, merge status, and code diff. After reviewing, you can approve the PR.
Ticket → auto-detects repo  |  URL → any repo in your org
🤖 Evaluate Copilot PR Comments
Analyzes GitHub Copilot code review comments on a PR. Uses AI to evaluate each suggestion, determine priority (High/Medium/Low), and recommend whether to apply it. Generates downloadable reports with categorized findings.
Ticket → auto-detects repo  |  URL → any repo in your org
ⓘ Requires AI provider configuration in Settings (OpenAI or GitHub Models).
Reports are optimized for GitHub Copilot with:
• ✅ Actionable checklists  • 🔗 Direct VS Code links  • 🤖 Copilot command templates
📁 Saved to Documents\Copilot Review\ (auto-cleanup: keeps last 20 files, max 30 days)
🚀 Create Release Branch
Creates a release branch from develop, automatically merges all open PRs, detects conflicts, and optionally creates a PR to UAT or Production.
Format: X.Y.Z (e.g., 3.51.0)
Leave blank to only create the branch and merge tickets
ℹ This will:
1. Create feature/{version} branch from develop
2. List all open PRs targeting develop
3. Merge each ticket into the release branch
4. Detect and report any merge conflicts
5. Optionally create a PR to UAT/Prod (if env selected)
